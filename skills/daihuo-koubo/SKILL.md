# 带货口播稿

写一条能念、能卖、像真人说话的带货口播。

## 什么时候用

- 用户给了产品名/卖点，要一条视频稿
- 用户给了一条对标爆款，要照着改一条
- 用户有一条自己写的稿，念着别扭，要改顺
- 用户要"几条不同的开头"或"换个角度再写一版"

不适用：直播话术（那是另一套节奏）、纯图文笔记、投放素材脚本。

## 写之前先确认三件事

信息不全就先问，别猜着编：

1. **卖什么** —— 品类 + 具体产品 + 价格带
2. **卖给谁** —— 人设是达人自用推荐，还是素人分享，还是店家
3. **要什么结果** —— 纯分享、挂车出单、还是立人设

用户没给就默认：达人口播、挂车出单、第一人称自用推荐。

## 稿子的骨架

一条 40 到 90 秒的口播，走这五步，顺序别乱：

1. **第一句就是判断**。不铺垫、不自我介绍、不"今天给大家分享一个"。
   例：「这个品我劝你别买贵的，贵的和便宜的差在一个地方。」
2. **讲为什么**。别讲道理讲成课件，把道理落在具体使用场景上。
3. **给一个能立刻用的判断标准**。观众听完知道怎么挑、怎么用、怎么避坑。
4. **算一笔账**。多少钱、能用多久、一次摊多少，边算边说，让数字自己说话。
5. **收尾一句能被记住的话**。可以轻引导，但不能是硬广。

教程型稿件（教观众做一个动作/一种玩法）允许用"第一步、第二步、第三步"。
论点型稿件（讲一个判断、一个道理）**不许**用数字分点。

## 硬规则

以下每条都是硬性要求，违反就重写，不要解释。

**开头**
- 第一句必须是判断句或反常识结论。出现"大家好""今天分享""最近很多姐妹问我"这类开场，直接废掉重写。
- 前三秒只干一件事：让人不划走。

**语言**
- 句子要碎。真人说话是断的、会重复、会自己接自己的话。
- 允许并鼓励自问自答：「为啥？留不住人呗。」
- 允许边算账边说话，允许口头禅点缀：你知道吧 / 说实话 / 我跟你讲 / 好家伙。
- 写完通读一遍，**太通顺、太工整的句子要故意拆碎**。

**连接方式**
- 论点型稿件不用"第一、第二、第三"，用「而且 / 再说 / 还有一点 / 最关键的是」过渡。

**行业词**
- 行话是低频调料，不是主菜。整条稿子里 ROI、投产比、转粉率、完播率、标签、SOP 这类词最多出现一两次。
- 概念一律翻译成日常话：保本 ROI →「卖一单剩多少、广告费花多少能回本」；完播率 →「观众第几秒划走」；标签 →「让平台知道把你推给谁」。
- 可以保留的口语带货词：点车、购物车、出单、佣金、投流、自然流、爆款、跟品。

**禁用的东西**
- 禁课件式小标题：「定位路径」「选品逻辑」「脚本结构」「素材拆分」「剪辑重点」「投流验证」——这些不是带货人会说的话。
- 禁花哨比喻：收房租、开卷考、擂台、彩票、滚雪球。听着像外行。
- 禁形容词堆叠：「超级超级好用」「真的绝了」「无敌了」。

**数字**
- 单量、佣金、营业额、粉丝数**沿用用户原稿，不自己编**。用户没给就不写具体数字。
- 只有用户明确说"这是我的数据"才改；否则原样保留。

**身份**
- 第一人称，口吻是有结果的前辈带新人，不是旁观者推荐。
- 身份元素点到为止：一条稿子最多轻轻带一句，不堆身份。
- 不说"跟我做""我带你"这类话，营销性太强，容易违规。

## 仿写对标稿时

同主题仿写 = **仿结构 + 换表达**：

- 保留：开头钩子的类型、推进顺序、骨架、收尾方式、观点本身
- 换掉：所有句子表达，重复率必须低，不能有大段雷同成句
- 举例可以换成同性质的新例子（不同品类、不同使用场景）
- 数字原样保留

## 输出格式

直接给稿子，前面不加方法论说明。需要多个版本时：

```
## 版本一（角度：____）
（稿子正文，一行一句，方便直接念）

## 版本二（角度：____）
（稿子正文）
```

每个版本 30 到 120 字左右一屏，段落短。不要在稿子里加括号注释、不要加"（此处停顿）"这类提示。

## 交付前自检

写完对着这七条过一遍，有一条不过就改：

1. 第一句是判断句吗？删掉它，稿子还成立吗？成立就说明它没用，重写。
2. 有没有"第一、第二、第三"？（教程型除外）
3. 有没有出现课件式小标题？
4. 行话超过两个了吗？
5. 有没有花哨比喻？
6. 数字是我编的，还是用户给的？
7. 念一遍，是不是太顺了？太顺就拆碎。
